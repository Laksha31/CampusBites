# CampusBites 🍔

A Data Science-powered food discovery platform
for UPES students.

## Project Overview

CampusBites brings all food outlets on the
UPES campus into one platform.

Students can:
- Explore food menus
- Compare prices across shops
- Rate dishes and share reviews
- Discover popular food items
- Get personalized food recommendations

## Technology Stack

- Python
- Pandas and NumPy
- Scikit-learn
- FastAPI
- PostgreSQL
- React
- Plotly
